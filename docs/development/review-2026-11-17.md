## Findings and corrections

- **Blocker — privacy:** the new cockpit counted personal to-do rows and published exact
  per-workspace activity outside the existing small-group/complementary suppression rules.
  Reuse the protected Activity builders; remove workspace descriptions, raw counts and content
  links. Personal storage charges are excluded. Regression tests seed recognisable private work.
- **High — application decisions:** approval/rejection and duplicate submissions could race;
  identities were not always rechecked and stale/private affiliation choices could grant an
  unintended home. Serialize decisions under existing admin/workspace/identity locks, validate
  active organisation units, require an explicit affiliation, recheck final identities, retain
  pending records on conflict and return bounded retry errors. Approval creates an invited member
  only. Register both decisions in the audit catalogue. No pushed migration was edited.
- **High — Windows:** two independent disk fallbacks invented inode availability; one patched
  global os.statvfs. Remove both, retain measured free bytes, expose unknown inode capacity.
  Use the Windows selector event loop through the HTTPS CLI; mark uvloop Linux-only. Managed
  Linux operator actions refuse to run without their required locking/deadline guarantees.
- **Medium — truthful operations:** use full event totals and explicit severity ordering; active
  steward coverage; fresh-or-unknown latency (including valid zero); no invented peak hours or
  healthy storage headroom. Enabled accounts are labelled as enabled, not adoption.
- **High — member delivery/data safety:** discard old dashboard/agenda responses on grant
  changes, use site-local calendar bounds, confirm task saves before success, and undo against
  the exact saved revision and previous status. Preserve note drafts and show failures. Dialogs
  trap/restore keyboard focus; review filters reject late responses, support pagination and
  report clipboard failures. Fix undefined colour tokens and remove text-fade contrast flicker.

The new workbench was split into small cards and request hooks; the application approval dialog
