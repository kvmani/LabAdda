## Bugs fixed in this review

| Area | Bug | Fix |
| --- | --- | --- |
| Security | Sign-in rate limiter never forgot keys; made-up usernames grew memory without bound | Idle keys swept once the table is large |
| Security | `POST /auth/password` had no attempt limit (its twin `/me/password` had one) | Same limit and key; refusals audited |
| Audit | A refused sign-in read "Bharat signed in."; one for an unknown username read "Operator tooling signed in." | Refused entries have their own wording ("A sign-in attempt for … was refused.") |
| Audit, Events | "Clear filters" followed quickly by another filter brought the cleared filters back (stale router parameters) | Shared `useFilterParams` hook edits from the newest parameters |
| Audit | Export file named by the host clock date, not the site date | Site date (earlier commit) |
| Realtime | A JSON message that was not an object dropped the socket | Answered with `bad_message`; socket stays open |
| Settings | Fourteen counts and durations accepted 0 or negatives (0 reminder interval busy-loops the database; 0 idle minutes signs everyone out) | Start-up refuses them, naming the setting |
| Home | Workbench grid overflowed phones by 4 px | `minmax(0, …)` columns |
| Home | Team-space links were 15–16 px targets (WCAG 2.2 needs 24 px) | 24 px minimum targets |
| Help | Shelves showed in member order, then jumped to the steward order when workspaces loaded | Shelves wait for the reader's role |
| Account menu | "My profile" was no longer first, contrary to the people card | Restored to first |
| Operator | `labadda-status` stopped with a traceback when no backup status was readable | Reads as unknown (earlier commit) |
