## What this is for

You can add PDF documents and PNG or JPEG pictures to a post so colleagues can open them without asking you for a copy. Files stay with the post and follow the same access as the workspace.

## Before you start

Your site limits how many files one post may carry and how large each may be. The usual limits are five files of up to 20 MiB each. If you go over, LabAdda tells you which limit you reached.

## Steps

1. On the **Noticeboard** tab, write your post in the message box.
2. Next to **Attach**, choose the file button and pick one or more files from your computer.
3. Wait until each file name appears in the list under the box. You can remove a file with its **×** button before posting.
4. Choose **Post**.

## What happens next

The post shows each file: pictures appear as small previews you can click to open, and PDFs appear as links. People who can read the workspace can open them. Someone who is later removed from the workspace can no longer open the files, but copies they already downloaded stay with them.

## If something goes wrong

- If a yellow box about unresolved uploads appears, a file did not finish. Choose **Check upload result** first, because the file may have arrived. If it did not, choose **Retry same file**. Choose **Dismiss upload** to give up on it; this does not delete anything already stored.
- Keep the page open until uploads are resolved. The files are held only in your browser tab, so closing or reloading it loses them.
- **Post** stays unavailable while an upload is unresolved.
- If LabAdda says a file type is not allowed, save the document as a PDF or the picture as PNG or JPEG and try again.
