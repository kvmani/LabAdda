## What this is for

When a discussion produces something to do, you can turn it into a task without retyping. The task is a copy you review first. It remembers where it came from so you can find the original conversation later.

## Steps

1. On a noticeboard post or a chat message, choose **Create task**. For a whiteboard, choose **Create task from board** in its toolbar.
2. In **Task destination**, choose **My personal lists (private)** or a workspace you can write in.
3. In **Destination list**, choose a list.
4. Edit **Task title** and **Task description**.
5. If the destination has different readers from the place you are copying from, tick the box that confirms the text will be shared with them.
6. Choose **Save conversation task**. For a board, choose **Save board task**.
7. To go back to the source later, open the task and choose **View source reference**, then the link that starts with **Open source**.

## What happens next

A message says **Task saved**, and **Open destination tasks** takes you to the list. Later edits to the original message do not change the task. Attachments and board drawings are not copied.

## If something goes wrong

- If the form says to create a to-do list in the destination first, the destination has no list yet. Create one, then try again.
- If the board changed while you were filling in the form, choose **Load latest board context (keeps draft)**.
- If a save may not have gone through, choose **Retry same task copy**. It recovers the first attempt instead of making a second task.
- Only people who can read both the task and the original can open the source. Anyone else sees "Source unavailable or no longer accessible."
- On a board with nothing on it, **Create task from board** is greyed out. Add something first.
