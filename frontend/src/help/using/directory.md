## What this is for

The staff directory helps signed-in colleagues find work contacts. It does not grant workspace access.

## Steps

1. Open **Staff Directory**.
2. Use **Search staff directory** to search by name or work details.
3. Review the matching contact cards and use the filters to narrow the list.

## What happens next

Matching staff profiles show the contact details supplied for the directory.

## If something goes wrong

Clear a filter if no one matches. Ask your administrator to correct staff-record details.
