## What this is for

The **Feedback** button is in the top bar on every page. Use it to tell the administrators about a problem, a suggestion or a question. Administrators will read this message and its attachments, so do not include passwords.

## Before you start

Be on the page where the problem happened. The form notes which page you were on.

## Steps

1. Choose **Feedback** in the top bar.
2. Choose what this is about and write your message.
3. To add a screenshot, paste it into the form, drop a file on it, or choose **Attach screenshots or files**. You can attach up to five pictures, PDF or text files.
4. Check the details listed under **Sent with your message**: your username, the time, the software version and the page.
5. Choose **Send to the administrators**.

## What happens next

You see "Sent to the administrators" once your message is saved. The administrators also receive it by e-mail when the site has e-mail set up.

## If something goes wrong

If sending fails, your message and files stay in the form. Read the reason shown, fix it (for example remove a file that is too large) and choose **Send to the administrators** again. Sending twice by mistake does not create two messages.
