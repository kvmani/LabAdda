## What this is for

The whiteboard keeps changing. A snapshot is a picture of one part of it, taken now and posted on a noticeboard, that never changes afterwards. Use it to record a plan or a result.

## Steps

1. Open the **Whiteboard** tab.
2. Choose **Publish snapshot**. A message asks you to drag on the board.
3. Drag across the part of the board you want, so a dashed box surrounds it.
4. In the **Publish snapshot** window, check the preview picture.
5. In **Post to**, choose where it should go: this workspace or its parent unit.
6. Edit the text in **Summary** if you wish.
7. If you chose a parent unit, tick the box that says everyone who can read it will see the image.
8. Choose the button that starts with **Publish to**.

## What happens next

A post appears on that noticeboard with the picture, the summary and a link back to the board. Later drawing, erasing or restoring does not change the post.

## If something goes wrong

- If the button is greyed out, the summary is empty or you have not ticked the box for a wider audience.
- If nothing happens after you drag, the box was too small. Drag a larger area.
- The picture shows the board as it was at the moment you started, not the live board.
- To stop, choose **Cancel**. Nothing is posted.
