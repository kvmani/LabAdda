## What this is for

**My Tasks** collects your own tasks and any shared tasks that someone has assigned to you, so you do not have to visit each workspace. It lists tasks only from workspaces you can currently open.

## Steps

1. Choose **My Tasks** under **Personal** in the left-hand list.
2. To narrow the list, open **My Tasks state** and choose **To do**, **In progress**, **Blocked** or **Done**. The default is **All states**.
3. Read each card for its title, state, priority, due date and the list it belongs to.
4. Choose **Open list** on a card to go to that list and update the task.
5. Choose **More My Tasks** to see further down the list.
6. Choose **Refresh My Tasks** to load the latest.

## What happens next

Updating a task in its list changes it here too. When a shared task is assigned to you or changes, a notice says it may have changed. Choose **Refresh My Tasks** to see it.

## If something goes wrong

- If a task you expect is missing, check **My Tasks state** is set to **All states**. If it was in a workspace you have since left, it is hidden but not erased.
- If the page says access changed while loading, choose **Refresh My Tasks** to start again.
- You cannot change a task from this page. Open its list first.
