## What this is for

You can send PDF, PNG and JPEG files in chat, in the main stream or inside a thread. Anyone who can read the chat can open them.

## Before you start

Sites limit the number and size of files. The usual limit is five files of up to 20 MiB each per message.

## Steps

1. Open the **Chat** tab of the workspace, or open a thread with **Open thread**.
2. Under **Attachments**, choose the **Attach files** button and pick your files.
3. Wait until each file name shows in the list. To drop one, choose its **Remove file** button.
4. Type a message if you want to add words, then choose **Send** (or **Send reply** in a thread).

## What happens next

The message appears with the file below it. Pictures show a small preview. Access is checked each time someone opens a file, so a person who is later removed from the workspace cannot open it again.

## If something goes wrong

- If an upload stalls, a message appears with **Check upload result** and **Retry same file**. Check first, because the file may already have arrived. **Dismiss upload** gives up on the file without deleting anything stored.
- Keep the page open until uploads finish. Files in progress are held only in this browser tab.
- If the message may not have been sent, use **Retry same message**. Your files and text are kept so nothing is attached twice.
- You cannot send a message with a file still uploading.
