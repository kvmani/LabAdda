## What this is for

**My storage usage** shows how much space the files you uploaded take up. The site has a limit for each person, so check this page if an upload is refused.

## Steps

1. Choose **My storage usage** under **Personal** in the left-hand list.
2. Read **Tracked original uploads**. This is the total size and number of files you uploaded.
3. Compare it with **Current pilot limit**, the most the site allows you.
4. Read **Uncommitted uploads** and **Pending original-byte reservations**. These are files started but not yet attached to a post or message.
5. Choose **Refresh usage** to see the latest figures.

## What happens next

The figures are shown in KiB, MiB or GiB, with the time they were **Observed**. Only the original files count against your limit.

## If something goes wrong

- If the page says **Unknown** next to previews, some picture previews were never measured. That is shown honestly, and does not count against your limit.
- The page says it covers only part of the picture. It does not include whiteboard history or text, which are shared storage.
- If an upload is refused for size, ask your administrator about the limit. Removing a post does not always free space immediately.
- A workspace's own files are on its **Storage** tab, which stewards can read about in [workspace storage](../stewards/workspace-storage.md).
