## What this is for

**My profile** shows the staff record your administrators keep for you and the units you can reach. It is also where you change your password and sign out browsers you no longer use. Only you can see this page.

## Steps

1. Choose your name at the top right of any page, then choose **My profile**.
2. Read **My record** and **My access**. You cannot edit these. To correct a detail, ask an administrator.
3. To change your password, fill in **Current password**, **New password** and **Repeat new password**, then choose **Change password**. Use at least 10 characters.
4. Look through **My sessions**. Each line is a browser where you are signed in, with when it started and when it was last used.
5. If you do not recognise a session or no longer use it, choose **Sign out this session** beside it.

## What happens next

When your password changes, every other browser is signed out at once and must use the new password. The browser you are using stays signed in. Signing out a single session works the same way for that browser only.

## If something goes wrong

- If **Current password** is rejected, retype it carefully. After several wrong tries you must wait a few minutes before trying again.
- If the new password is refused, make it longer or different from the current one. What you typed stays on the screen so you can fix it.
- If you have forgotten your current password, ask an administrator for a reset link instead.
- If the page says it could not be loaded, check your connection and choose **Try again**.
