## What this is for

Each workspace has its own chat for quick questions and day-to-day talk. Only people who can read the workspace see its messages. Use a thread to keep a side conversation from cluttering the main stream.

## Steps

1. Open the workspace and choose the **Chat** tab. A number beside the tab, such as 3 new, shows unread messages.
2. Type your message in the box that starts with **Message** and choose **Send**.
3. To reply in a thread, choose **Open thread** under a message. The **Thread discussion** panel opens. Type in **Thread reply** and choose **Send reply**.
4. To close the thread panel, choose **Close thread**.
5. To tell the whole workspace about a message, choose **Share to noticeboard**, check the text and the destination, and choose the button that starts with **Post to**.
6. To follow up on a message with a task, choose **Create task**. See [turning a message into a task](task-from-a-message.md).

## What happens next

New messages appear on their own. Thread replies also appear in the main stream, marked **Thread reply**. The unread number clears once you have the chat open.

## If something goes wrong

- If the screen shows **Offline** at the top, your connection dropped. LabAdda reconnects by itself and then catches up.
- If new messages do not appear, choose **Refresh chat**.
- To read older messages, choose **Load earlier messages**. While you do, new messages wait; choose **Return to latest messages** to go back.
- If a message may not have been sent, the button changes to **Retry same message**. Choose it rather than typing the message again, so it is not sent twice.
- If you see **Chat is read-only here.**, you can read but not write in this workspace.
- Sharing to a different workspace asks you to tick a box first, because more people will see the text.
