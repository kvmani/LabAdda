## What this is for

The **Feedback** page lists everything people sent with the Feedback button. People are told that administrators will read their message and attachments, so this is the one place where you read what someone wrote. Each time you open a message or a file, the audit trail records that you did.

## Steps

1. Choose **Feedback** in the administration menu.
2. Filter by **Status** or **Kind** if the list is long.
3. Choose a page name in the **Page** column to open the message.
4. Read the message, the details (username, time, software version, commit, page, browser and screen size) and open any attached files.
5. Change **Status** to **Seen** or **Resolved**, add an **Administrator note**, and choose **Save status and note**.

## What happens next

The sender is not notified. The list shows the new status. The **E-mail** column shows whether the e-mail copy was sent, is waiting, or failed.

## If something goes wrong

If the page says **E-mail not configured**, feedback is still saved here; ask the person who looks after the server to set up the mail settings. If an e-mail failed, the reason is shown in the message; choose **Send e-mail again** after the cause is fixed. If someone else saved the message first, reload it and save again.
