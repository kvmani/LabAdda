## What this is for

Use this when someone goes on long leave or deputation. Their access stays unless you block sign-in. If they hold a position, you can appoint an acting replacement for the time they are away.

## Before you start

You need to be a site administrator. Only active people can go on leave. Know the expected return date.

## Steps

1. Open **People**, select the person, and on the **Record** tab choose **Record long leave**.
2. Choose the **Expected return date**.
3. Tick **Block sign-in while away** only if they must not sign in during the leave.
4. For each position they hold, optionally choose an acting replacement.
5. Choose **Review change**, type the **Reason for this change** and confirm, then choose **Done**.

When they come back, open their profile and choose **Record return from leave**, then confirm the review.

## What happens next

The person's status becomes on leave. If sign-in is blocked, their open sessions end at once. Acting replacements hold the position until the expected return date. Recording the return makes the person active again and ends the acting appointments made for the absence, returning those people to their earlier roles. An overdue return never changes access by itself.

## If something goes wrong

- "Only active people can go on leave". Check the person's status on the profile.
- "already has an acting Head". Change that appointment first.
- "At least one active administrator must remain". Do not block sign-in for the last administrator.
