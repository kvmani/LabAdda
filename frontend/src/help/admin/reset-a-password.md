## What this is for

Use this when a person has forgotten their password or never used their first code. You issue a one-time code and hand it over; you never see or choose their password.

## Before you start

Confirm who the person is before you give them a code, for example in person. You need to be a site administrator.

## Steps

1. Open **Administration**, choose **People**, then choose **Basic account tools**.
2. Find the person in the staff table. A person who has not yet signed in shows **Pending activation**.
3. Choose **Reset** on their row. The page shows a reset code for that username.
4. Give the person the code and the sign-in address. They enter it and choose their own password.

For a person who is still waiting for their first sign-in, you can instead open their profile on **People** and choose **Issue a new activation code**, type a reason and choose **Issue new code**.

## What happens next

The old password stops working. The code is shown once and expires; if it is lost, issue another. The reset is recorded in **Audit**.

## If something goes wrong

- The code expired. Choose **Reset** again.
- The person is shown as **Disabled**. Reinstate them first; see the suspend and reinstate page.
