## What this is for

The **Needs attention** list on **People** shows things that nobody will notice by themselves. The same items appear on the Overview. Each one names the page that fixes it. An item disappears as soon as the problem is fixed.

## Before you start

You need to be a site administrator. The list shows names and counts only, never anyone's work.

## Steps

1. Open **People** and read **Needs attention**.
2. Choose **Open the page that fixes this** beside an item.
3. Fix it there, then come back. The item is gone.

The list covers:

- units with no active steward or Head;
- people with no home unit;
- activation codes waiting more than 14 days;
- acting appointments ending within 14 days, and ended ones where nobody now holds the position;
- people past their expected return from leave;
- scheduled changes that need review;
- projects and groups with no active steward;
- accounts that have never signed in after 90 days.

## What happens next

Nothing is changed for you. When an acting appointment ends and leaves a unit with no steward, the unit appears here so that someone is appointed.

## If something goes wrong

- If an item does not go away, reload the page. It is checked again each time.
- A scheduled change that needs review was not applied. See the page on scheduling a change.
