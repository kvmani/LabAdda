## What this is for

Every group needs at least one steward. If you are moving on, make someone else a steward first, so the group is never left without anyone to look after it.

## Before you start

The person must already be a member of the group. If not, add them first (see [adding and removing members](members-and-roles.md)). For a unit or project, the steward is set by an administrator, so ask them instead.

## Steps

1. Open the group and choose the **Members** tab.
2. Find the colleague in the table and choose **Make steward**. Their role changes to **Steward**.
3. Tell them. They do not get an alert.
4. If you want to stay in the group as an ordinary member, find your own name and choose **Make member**.
5. If you want to leave the group entirely, choose **Leave group** beside your name and confirm.

## What happens next

The new steward can add and remove people and use all the other steward buttons straight away. If you made yourself an ordinary member, those buttons disappear for you. If you left, you can no longer open the group.

## If something goes wrong

- If LabAdda says "Make another member a steward first.", you are the only steward. Complete step 2, then try again.
- If the table does not show **Make steward**, you are not a steward of this group.
- A steward can be changed back at any time by another steward.
