## What this is for

Sometimes a workspace should be kept for reading only, for example while a project is wrapping up or after a decision is final. You can make it read-only, which keeps it open for stewards, or archive a group, which locks it for everyone.

## Steps

1. Open the workspace and choose the **Members** tab.
2. To stop ordinary members from posting, choose **Make read-only for members**. In a unit or project this is in the card called **Posting policy**. In a group it is under **Group settings**.
3. To let them post again, choose **Reopen posting**.
4. To archive a group, go to **Group settings** and choose **Archive group**. Read the question and confirm.
5. To bring an archived group back, choose **Unarchive group**.

## What happens next

When posting is closed, members still read everything but see **Posting is limited to stewards in this workspace.** and chat says it is read-only. Stewards can still post. In an archived group nobody can post, chat, draw or add tasks, and everything stays readable. The workspace is marked **Archived** in the left-hand list.

## If something goes wrong

- If you cannot see the buttons, you are not a steward, or the workspace is already archived.
- If members tell you they cannot write, check whether the status under the workspace name says **Read-only**.
- Archiving a unit or project is done by an administrator.
- Nothing is deleted by archiving. Unarchiving restores it as it was.
